# По полочкам

Небольшие учебные страницы для школьника. Обычные HTML, CSS и JavaScript; сборка и серверная часть не нужны.

## Уроки

- [Химия, 10 класс — алканы](./chemistry-10-alkanes/): гомологический ряд метана, CₙH₂ₙ₊₂, sp³-гибридизация, вращаемая модель CH₄, 12 тренировочных заданий и самопроверка из 6 вопросов.

- [Геометрия, 10 класс — параллельность прямой и плоскости](./geometry-10-line-plane/): три случая расположения, признак и свойство параллельности, пошаговое сечение куба, 12 заданий и самопроверка из 6 вопросов.

Прогресс хранится в `localStorage` браузера отдельно для каждого урока. Внешние библиотеки, шрифты и сетевые запросы для работы урока не используются.

## Локальный запуск

Из каталога репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Для проверки путей с префиксом `/School/` в облачной среде:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory /workspace
```

Стартовая страница находится в `/School/`, урок — в `/School/chemistry-10-alkanes/`.

## GitHub Pages

В репозитории настроен workflow `.github/workflows/static.yml`. Каждый push в `main` запускает публикацию всего статического сайта; предусмотрен и ручной запуск из Actions. В **Settings → Pages → Source** должен быть выбран **GitHub Actions**.

Сайт: `https://julia-1093.github.io/School/`. Результат нового развёртывания проверяется в Actions. Файл `.nojekyll` отключает ненужную обработку Jekyll.

## Новая тема

Создайте папку с `index.html`, используйте относительные пути к ресурсам и добавьте ссылку в корневой каталог. Для проверки урока пройдите верный и неверный ответы, повторную попытку, сохранение после перезагрузки и итоговую проверку. На узком экране проверьте отсутствие горизонтального выхода содержимого и доступность всех кнопок.

## Проверка

В облачной среде доступны Python Playwright и `/usr/bin/chromium`:

```sh
python3 -m unittest discover -s tests -v
```

Проверки охватывают оба урока: модели и схемы, все задания практики, итоговую проверку, раздельное сохранение прогресса, клавиатурное управление и экраны шириной 320, 390 и 768 пикселей. Сервер для тестов запускается и останавливается автоматически.
