Базовый маршрут

Сначала свойства корней и степеней, затем уравнения и неравенства. Отдельный блок со звёздочкой можно пройти после основных заданий.

01
Что означает знак корня

Корень — число, а не два ответа сразу.

Корень n-й степени

Ищем b, для которого bn = a.

Показатель n — целое число, n ≥ 2. Но чётность n меняет область определения и знак результата.

n чётное

Нужны a ≥ 0 и b ≥ 0. Арифметический корень всегда неотрицателен.

√16 = 4; ∜16 = 2

n нечётное

a может быть любым действительным числом. Знак корня совпадает со знаком a.

∛(−27) = −3

Не путай корень и уравнение.Уравнение b⁴ = 16 имеет решения −2 и 2. Но запись ∜16 обозначает только число 2.
Исследуй кореньВ действительных числах

Попробуй a = −27 при n = 3, а затем при n = 2. Знак ≈ появляется, если значение округлено до трёх знаков.

√(a²) = |a|

При a = −5 получаем √25 = 5. Снять квадрат и корень без модуля здесь нельзя. Для нечётного n верно ⁿ√(aⁿ) = a.

Корень суммы не разбивается

√(9 + 16) = 5, а √9 + √16 = 7. Правило √(ab) = √a · √b для a, b ≥ 0 относится к произведению, не к сумме.

От показателя зависят область определения, знак и монотонность. Сравни четыре характерных примера.

03
Дробь в показателе степени

Знаменатель — корень. Числитель — степень.

Для a > 0
amn=(an)m

m — целое, n — натуральное, n ≥ 2. Здесь свойства рациональных степеней формулируем для положительного основания.

Два примера

272/3 = (∛27)² = 9

16−1/2 = 1 / √16 = 1/4

Отрицательный показатель означает обратное число. Это не минус перед результатом.

ar · as = ar+sar / as = ar−s(ar)s = ars

В этих правилах a > 0. Нулевое основание допустимо при положительном показателе: 0r = 0 для r > 0. Записи 0⁰ и отрицательные степени нуля здесь не определены. Корни нечётной степени из отрицательных чисел, например ∛(−8), рассматриваем по определению корня.

04
Иррациональное уравнение

После возведения в квадрат нужен контроль.

Базовый алгоритм

√f(x) = g(x)

  1. Запиши ОДЗ: f(x) ≥ 0.
  2. Учти знак правой части: g(x) ≥ 0.
  3. Возведи обе части в квадрат.
  4. Отбери решения по условиям и проверь их в исходном уравнении.
√f(x) = g(x)
⇔ f(x) = g²(x) и g(x) ≥ 0

В этой равносильной системе f(x) ≥ 0 уже следует из f(x) = g²(x). Отдельная запись ОДЗ помогает не потерять смысл исходного выражения.

Нечётный корень работает иначе.

∛(2x − 1) = 3 ⇔ 2x − 1 = 27 ⇔ x = 14. Кубическая функция строго возрастает на всей ℝ: здесь не требуется условие «правая часть ≥ 0».

    05
    Иррациональные неравенства

    Перед квадратом посмотри на знак справа.

    Корень квадратный неотрицателен. Поэтому для знака «меньше» правая часть должна быть положительной, а для «больше» отрицательная правая часть даёт целую ветвь решений.

    Равносильные условия

    Здесь f и g обозначают значения выражений при одном и том же x. Если есть знаменатели, их ограничения тоже включаются в ОДЗ.

    Почему нельзя просто возвести в квадрат?Например, √1 > −1 — верное неравенство. После бездумного возведения в квадрат получилось бы 1 > 1, и решение потерялось бы.

      Два корня в одном уравнении

      √(x + 1) + √(x − 2) = 3

      1. ОДЗ: x ≥ 2.
      2. Возводим в квадрат: 2x − 1 + 2√((x + 1)(x − 2)) = 9.
      3. Изолируем корень: √((x + 1)(x − 2)) = 5 − x. Нужно x ≤ 5.
      4. На промежутке [2; 5] снова возводим в квадрат: x² − x − 2 = (5 − x)².
      5. Получаем 9x = 27, x = 3. Проверка: √4 + √1 = 3. Ответ: {3}.

      ОДЗ с разрывом

      √(x² − 5x + 6) ≤ x − 1

      1. ОДЗ: (x − 2)(x − 3) ≥ 0, значит x ≤ 2 или x ≥ 3.
      2. Правая часть неотрицательна: x ≥ 1.
      3. После квадрата: x² − 5x + 6 ≤ (x − 1)².
      4. Отсюда x ≥ 5/3.
      5. Пересекаем все условия: [5/3; 2] ∪ [3; +∞). Промежуток (2; 3) запрещён ОДЗ.

      Памятка

      Не потеряй условия, пока меняешь выражение.

      1. Для чётного n: ⁿ√a определён при a ≥ 0 и неотрицателен. Для нечётного n корень определён при любом действительном a.
      2. √(a²) = |a|. При a > 0: am/n = (ⁿ√a)m; a−r = 1/ar.
      3. Уравнение √f = g равносильно условиям f = g² и g ≥ 0. Проверяй кандидатов в исходной записи.
      4. √f < g ⇔ f ≥ 0, g > 0, f < g². Для «≤» оба последних знака нестрогие.
      5. Для √f > g сначала учти ветвь f ≥ 0, g < 0. При g ≥ 0 сравнивай f и g². Для «≥» неположительная правая часть подходит автоматически на ОДЗ.
      6. Ответ неравенства — пересечение условий или объединение подходящих ветвей. Проверь каждую границу и вид скобок.
